# Guías how-to

Referencias en formato receta para las tareas de extensión más comunes. Son breves y asumen que ya leíste el capítulo correspondiente en `follow_along/` — te dicen *cómo*, no *por qué*.

| Guía | Cuándo la necesitas |
|---|---|
| [Añadir una herramienta nueva](add-a-tool.md) | El modelo necesita una capacidad nueva — `web_fetch`, `grep`, `git_log`, cualquier cosa que puedas implementar en Go |
| [Añadir un proveedor nuevo](add-a-provider.md) | Quieres cambiar Anthropic por OpenAI, Bedrock, Ollama o un mock |
| [Añadir una política de permisos](add-a-permission-policy.md) | Quieres algo distinto a "preguntar cada vez" — auto-permitir herramientas de solo lectura, preguntar una vez por herramienta, denegar por ruta |

Cada guía es un ejemplo resuelto que puedes copiar. ¿Te falta una receta? Abre un PR.
